Setting up a Tobii eye tracker
  • A web page cannot read the eye tracker directly. It follows the mouse pointer, so the Tobii software must be set to move the pointer with the eyes. Windows Eye Control, Tobii Dynavox TD Control and Tobii Dynavox Computer Control can all do this.
  • If the check box above turns green when the user looks at it, dwell will work.
  • If the Tobii software also clicks by itself (its own dwell click), you can either keep this page's dwell on, or choose Off above and let Tobii do the clicking. This page will not select the same picture twice either way.
  • If the pointer shakes, a small wobble off a tile is forgiven. Try a longer dwell time if pictures get chosen by accident.
  • Use Chrome or Edge in full screen (press F11) for the biggest tiles.

A helper should click Start once with the mouse or touchpad. Browsers only allow speech after a real click.
